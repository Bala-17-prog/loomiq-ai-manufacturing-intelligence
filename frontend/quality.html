How It Works

  1. Image Validation
  2. Preprocessing (Grayscale Conversion, Noise Reduction)
  3. Texture / Intensity Analysis (Local Contrast Analysis)
  4. Anomaly Detection (Thresholding)
  5. Region Detection (Contour Detection)
  6. Visual Annotation
  7. Score Calculation
  8. Database Storage

This prototype uses explainable OpenCV image-processing techniques to identify visually unusual regions in fabric images. It is intended as a proof-of-concept and is not a production-grade textile defect classification model.
